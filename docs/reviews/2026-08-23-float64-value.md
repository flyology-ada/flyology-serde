# Binary64 logical value review — 2026-08-23

Scope: safe representation of finite and nonfinite binary64 categories across the serializer/deserializer boundary.

## Trigger

A CBOR writer test constructed IEEE positive infinity from raw bits. GNAT raised `Constraint_Error` for invalid data
at the `Interfaces.IEEE_Float_64` parameter boundary. The original event type therefore could not safely carry the
nonfinite categories promised by `Format_Capabilities`.

## Findings resolved

- P1: a raw Ada float parameter cannot portably carry infinity or NaN under validity checking. The logical event now
  uses a private semantic value with an explicit category and an always-valid finite slot.
- P1: a discriminated wrapper used as an `out` result could fail copy-out for a constrained actual whose category
  changes. The wrapper is definite and non-discriminated, so every actual has the same representation.
- P1: decoding nonfinite CBOR bits through an Ada float would recreate the validity failure. The CBOR contract now
  requires exponent/significand classification before conversion; only proven-finite bits become Ada floats.
- P2: default initialization, signed-zero preservation, accessor preconditions, all three nonfinite categories,
  capability meaning, and canonical CBOR category encodings are explicit.
- P2: nullary value functions provide nonfinite values instead of new visible constants, following the repository's
  shared APM rule.
- P2: implementation review added an explicit positive-zero bit assertion for default state, direct constructor
  category checks, and focused counting-capability checks.
- P2: JSON documentation now separates per-event no-output rejection from the adapter's whole-traversal capability
  preflight guarantee.

## Review disposition

The independent architecture review found no P0 or remaining P1. `Finite_Value` has a category precondition;
backends and adapters case on `Category` first. A public raw-bits event was rejected because it would add NaN payload
and signaling representation identity to the format-agnostic logical contract.

Implementation review must cover default state, constructors, finite access including both signs of zero, JSON
pre-output rejection, counting acceptance, fixed CBOR nonfinite bytes, and bit-first binary16/32/64 decoding.
